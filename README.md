## Description
Веб-приложение для фрилансеров в сфере дизайна и визуализации. Используйте:

[✅] Менеджер проектов, поддерживающий фильтры по статусам и заказчикам; 

[✅] Версионирование: позвольте заказчику видеть все версии проекта в одном месте; 

[✅] Защита от копирования: заказчики видят автоматические превью с вотермарками;

[✅] Все файлы в Облаке - никуда не исчезнут и доступны только Вам.
